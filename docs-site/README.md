# TrailTracker docs site

Nextra 4 (App Router) documentation site for TrailTracker. This is a separate
website project: npm dependencies live here and only here — the Rust runtime
crate stays zero-dep.

## Dev

```sh
npm install
npm run dev        # http://localhost:3000
```

## Static build

```sh
npm run build      # regenerates the CLI reference, then next build → out/
npm run start      # serve out/ locally (npx serve)
```

The build is a fully static export (`out/`): no server required, no external
fonts or CDN assets at runtime. Search is Pagefind, indexed at build time into
`out/_pagefind/`. Serve with any static host that maps `/page` →
`page.html` (`npx serve` does; python `http.server` does not).

## Generated content

`content/cli-reference.mdx` is generated by
`scripts/generate-cli-reference.mjs` from the binary's own
`trailtracker capabilities` JSON — do not edit it by hand. The script prefers
a built binary (`TRAILTRACKER_BIN` or `../target/release/trailtracker`) and
falls back to the committed snapshot in `generated/capabilities.json`.

All other pages cite repo sources (README.md, docs/, benchmarks/,
mcp/README.md); output snippets were captured from real runs of the binary
against this repository.

## Notes

- `overrides.zod = 4.3.6` in package.json pins zod: 4.4.x rejects missing
  keys that `z.custom()` would accept, which breaks nextra-theme-docs 4.6.1's
  `LayoutPropsSchema` (it strips `children` before parsing). Remove the pin
  once nextra > 4.6.1 fixes this.
- Deploying (Vercel or elsewhere) is deliberately not wired up — publishing
  is a separate decision.
